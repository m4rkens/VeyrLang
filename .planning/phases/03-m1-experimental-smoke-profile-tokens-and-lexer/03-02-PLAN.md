## Scope and ownership contracts

Reuse SourceManager text/span/location operations and existing DiagnosticEngine;
do not modify either public API. Borrow one immutable source view during lex,
return owning token values, and require the originating manager to outlive later
lexeme resolution. Views survive new registrations, not manager destruction.
Coincident IDs from other managers are caller-contract errors that the current
numeric SourceId API cannot automatically distinguish. Do not claim otherwise.
Diagnostic messages own their strings, source spans remain manager-local, and
engine views must be reacquired after emit. Explicitly initialize severity.
Allocation failures retain ordinary existing C++ exception semantics; do not
invent an OOM policy, atomic batch emission or diagnostic rollback guarantee.

The lexer recognizes lexical units, not fixed-program structure, 0–255 range,
final types or ABI. No parser/AST/semantics/backend/driver/filesystem, token trivia,
accepted comments, Unicode decoding, new dependency or language warning policy.
Conan 2.33.0, LLVM 23.1.2, four locks, recipes/profiles/baselines/workflows and
prepared caches remain unchanged. Use canonical owned includes `<veyr/...>`.
