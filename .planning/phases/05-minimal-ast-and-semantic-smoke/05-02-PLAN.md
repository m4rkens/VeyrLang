## Required structural matrix — eighteen independently executed rows

| Row identities | Expected result |
|---|---|
| UnknownEntry, UnknownReturn, UnknownInteger | exact UnknownSource for that field, no AST error/diagnostic |
| ReversedEntry, ReversedReturn, ReversedInteger | exact ReversedRange, original begin/end/source_size |
| BeyondEntry, BeyondReturn, BeyondInteger | exact BeyondSource, original begin/end/source_size |
| ReturnSourceMismatch, IntegerSourceMismatch | AstError SourceMismatch, correct field/span, null offset |
| EmptyEntry, EmptyReturn, EmptyInteger | valid source empty range → AstError EmptySpan |
| ReturnBeginTouchesEntry, ReturnEndTouchesEntry | NonNestedSpan Return |
| IntegerBeginTouchesReturn, IntegerEndTouchesReturn | NonNestedSpan Integer |

For every AstError assert kind, field, exact offending span and absent byte_offset;
for every SourceError assert all five original fields. Reacquire diagnostic views;
expect no new diagnostic and no successful alternative. Use known distinct sources
for SourceMismatch, not a numeric-ID collision between different managers.

LaterSourceBeforeEarlierRelationship; SourceMismatchBeforeEmpty;

## Required decimal/content matrix — eighteen rows

Zero, One, TwoHundredFiftyFour, TwoHundredFiftyFive,
TwoHundredFiftySix, HugeDigits, ManyZeros, ManyZerosThen42,
ManyZerosThen255, ManyZerosThen256,
LetterSuffix, NegativeSpelling, PlusSpelling, EmbeddedSpace,
EmbeddedNul, HighByte, Dot, RangePrefixThenLetter.

Long rows use at least 65,536 literal bytes. For HugeDigits use all '9'; ManyZeros
is all '0'; leading-zero suffix rows have independently specified 42/255 success
or 256 range failure regardless of length. Content rows are checked AST errors at
the first offending absolute byte (28 plus known index), not semantic diagnostics.
RangePrefixThenLetter has at least 65,536 '9' followed by 'x'; it must be a checked
NonDecimalLiteral with zero newly emitted diagnostics despite prior numeric excess.
Assert success values and complete AST spans, or exact rejection/error alternatives,
with no partial value. Build embedded-NUL fixtures with an explicit string length, not a truncating C-string constructor; form high bytes explicitly without locale decoding. No stoll/strtol/production conversion oracle in tests.

## Required diagnostic-state matrix — five rows

ValidWithPriorErrorBlocked; RangeWithPriorErrorAppendsOne;
ValidWithNoteAndWarningSucceeds; DuplicateRangeErrorsPreserveOrder;
MalformedAstPreservesAllPriorFields.

Assert exact message `return value must be between 0 and 255 in M1 Experimental
Smoke Profile`, initialized Error severity, full literal primary including leading
zeros, empty related list, and all earlier severity/message/primary/related fields.
Duplicate calls append distinct identical diagnostics in order. Notes/Warnings
alone do not become Errors. No source/AST failure emits a user range Error.
