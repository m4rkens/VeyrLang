## Required independent integration identities

1. RealFixedEntryValidates — exact sample fn main() -> int32 { return 42; },
   entry [0,33), return [21,31), literal [28,30), signed constant 42, no diagnostics.
2. RealLeadingZerosAreDecimal — actual lexer/parser 00042 → 42.
3. RealBoundaryValues — separately traced actual source returns 0 and 255.
4. RealHugeDecimalRejects — parser succeeds for long digit shape; semantics alone
   appends one exact range Error for the complete literal, never partial success.
5. OwnedOutputOutlivesInputs — destroy caller strings, tokens, LexResult,
   ParseResult and input AST before inspecting successful output; manager alive.
6. CopiesAndMovesKeepCompleteContext — copy/move/assign validated values and
   compare all three spans, constant and original source text after input death.
7. ThreeThousandRegistrationsPreserveSnapshot — retain owned output/source views,
   add 3,000 sources, resolve exact original bytes and all three syntax bounds.
8. LexicalInvalidCannotReachSuccess — actual -1, 0x10, comment and high-byte input
   subcases; Invalid/Error retained, parse rejects, no AST/semantic success or
   duplicate semantic/parser Error. Explicitly branch, never default-construct AST
   and feed a failed parse into validate_smoke as if it were successful.
9. SyntaxFailureCannotReachSuccess — real missing semicolon/brace and trailing
   input; retain exact parser diagnostics and no AST/validated result.
10. PriorErrorBlocksValidPipeline — seed the same engine using a real lexical
    failure in another registered source, then independently lex/parse a valid
    entry; semantics must return BlockedByErrors without emitting or clearing
    anything. Trace a second subcase seeded by a real parser syntax Error.
11. PriorWarningNoteAllowsPipeline — real valid parse/semantics succeeds and
    retains both prior owning diagnostic values/order.
12. DuplicateRangeErrorsRemainOrdered — actual parsed out-of-range entry checked
    twice; two owning identical Errors in order, prior Errors remain, no success.
13. OriginalSpansAcrossLineEndings — literal LF/CRLF/lone-CR source variants with
    manually specified AST/range primary and source-location oracles. Example
    fn main() -> int32 {\r\nreturn 256;\r\n} has [0,36), [22,33), [29,32),
    literal location line 2 column 8; do not normalize original bytes.
14. CheckedSourceFailureRemainsDistinct — public forged AST referencing unknown
    source preserves SourceError and prior diagnostic fields, no source-language Error.
15. RangeDiagnosticRendersIndependently — render a copied owning Error through
    actual PlainTextRenderer; compare entire expected string independently and
    engine Error state. Destroy engine/input AST before reusing copied diagnostic
    and rendered std::string; source manager remains alive during rendering.
16. HostileNameIsEscaped — original display name includes ESC/newline/backslash
    and hostile path-like metadata; compare literal expected escaped renderer
    output using the existing renderer contract; no raw terminal controls/path IO.

Looped subcases require SCOPED_TRACE labels and retained subcase coverage, not
inflated CTest counts. No mocks replace production components and no renderer
expected string is generated by another call to the same renderer. Resolve every
checked variant explicitly; a recovered token vector or parser syntax success
alone cannot establish successful compilation. Do not test use after manager death.
