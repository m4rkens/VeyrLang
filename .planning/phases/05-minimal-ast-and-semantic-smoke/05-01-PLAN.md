## Exact public contract and validation order

Move the unchanged `veyr::ParsedSmokeEntry` definition (entry_span, return_span,
integer_span; SourceSpan fields and defaulted equality) into
`include/veyr/ast/smoke_entry.hpp`. Its only owned include is source_span.hpp.
parser.hpp includes it and preserves parse(), ParseResult and all other public
declarations. Do not create an alias to a second AST or change parser.cpp behavior.

Proposed semantic API, fixed by this reviewed plan when approved:
- `validate_smoke(const SourceManager&, const ParsedSmokeEntry&, DiagnosticEngine&)`
  is synchronous and [[nodiscard]], returning `SemanticResult`.
- `AstField { Entry, Return, Integer }`;
  `AstErrorKind { SourceMismatch, EmptySpan, NonNestedSpan, NonDecimalLiteral }`;
  `AstError { kind, field, span, byte_offset }` has those typed fields, SourceSpan
  span, and std::optional<std::size_t> byte_offset. Offset is present only for the
  first nondigit, measured from original source start. All other errors use nullopt.
- `SemanticRejectionKind { OutOfRange, BlockedByErrors }` and
  `SemanticRejected { kind }`; equality on error/rejection values.
- `ValidatedSmokeEntry` privately owns the complete ParsedSmokeEntry plus
  std::int32_t constant; `ast() const` returns ParsedSmokeEntry by value and
  `return_value() const` returns std::int32_t. Explicit public copy/move construction
  and copy/move assignment; no public default/payload constructor or mutation.
  Friend only the validator for private payload construction. Construct success
  inside the friend before moving it into the variant, not via std::variant's
  access to a private in-place constructor.
- `SemanticResult` has exactly SemanticRejected, SourceError, AstError,
  ValidatedSmokeEntry alternatives, with SemanticRejected first (no default success).
  Resolve forward declarations without weakening access. Ordinary exceptions
  retain existing C++ policy. No hidden global engine or cached source view.

Run checks in this exact order, with no emissions before the range stage:
1. Validate entry, return, integer spans through SourceManager; first exact
   SourceError wins, including a later span over an earlier relationship fault.
2. Same SourceId: return then integer compared with entry → SourceMismatch.
3. Nonempty entry, return, integer in order → EmptySpan.
4. Strict return-in-entry (begin then end), then integer-in-return (begin then end)
   → NonNestedSpan with Return or Integer respectively. Previous checks establish
   `entry.begin < return.begin < integer.begin < integer.end < return.end < entry.end`.
5. Resolve integer bytes with checked text(); preserve any SourceError. First
   byte outside ASCII 0–9 → NonDecimalLiteral and absolute offset.
6. Once all bytes conform, reject mathematical values above 255 with exactly one
   explicitly initialized Error, integer_span primary, empty related list, message
   `return value must be between 0 and 255 in M1 Experimental Smoke Profile`;
   return SemanticRejected::OutOfRange, never success.
7. Valid range plus existing engine Error → BlockedByErrors, emit nothing. Notes
   and Warnings alone do not block. Otherwise return owned success with exact AST.

Use constant bounded arithmetic: only update value while in [0,255], comparing
against 25 and final digit 5 before multiply/add. Latch out-of-range and continue
ASCII validation; a late nondigit outranks range rejection. Arbitrarily long zeros
do not create overflow or octal; never require host conversion of the whole input.
No language diagnostic for SourceError/AstError. No partial successful value on
any rejection. Preserve earlier messages/spans/order/duplicates and Error state.

Source IDs are manager-local and cannot prove foreign-manager provenance on a
numeric collision. The original manager must stay alive for source resolution.
Public AST checks do not reparse/certify arbitrary surrounding syntax. Existing
lexer/parser errors establish malformed-source diagnostics; checked AST misuse
is a separate infrastructure failure. Successful validation gates the current
engine state, not hypothetical future emissions. No driver/lowering is added.
