## Artifacts this phase produces (this plan)

- `source_id.hpp`: namespace `veyr`; strong `SourceId { std::uint64_t value }`, equality, default invalid sentinel 0. Valid IDs start at 1 and are local to one manager; no filesystem/hash/global registry identity.
- `source_span.hpp`: `SourceSpan { SourceId source_id; std::size_t begin; std::size_t end; }`, equality; no owned lexeme or newline/encoding flag.
- `source_manager.hpp/.cpp`: noncopyable/nonmovable `SourceManager`, out-of-line destructor, private completed `SourceRecord` objects held by `std::vector<std::unique_ptr<const SourceRecord>>`. Records own `std::string display_name`, `std::string bytes`; no erase/reset/replace API. Guard ID/index conversions before indexing.
- Public `[[nodiscard]]` APIs: `register_source(std::string display_name, std::string bytes) -> RegistrationResult`; `source_text(SourceId)`, `display_name(SourceId)`, `text(SourceSpan) -> TextResult`; `validate(SourceSpan) -> ValidationResult`. `RegistrationResult = std::variant<SourceId, RegistrationError>`; `TextResult = std::variant<std::string_view, SourceError>`; `ValidationResult = std::variant<std::monostate, SourceError>`.
- `SourceErrorKind { UnknownSource, ReversedRange, BeyondSource }`; `SourceError { kind, source_id, begin, end, std::optional<std::size_t> source_size }`. ID-only errors use zero offsets; unknown source has no known size. Precedence: unknown ID, reversed range, then end beyond size. Preserve the original supplied offsets.
- `RegistrationErrorKind { IdCapacityExceeded, SourceTooLarge }` / `RegistrationError { kind }`. Reject before insertion when another nonzero uint64 ID/index cannot be represented or source size exceeds `SIZE_MAX - 1` (one-based EOF locations need headroom). No partial registration or ID reuse. A private pure `registration_capacity_error(record_count, source_size)` helper returns the optional capacity error before arithmetic; an explicitly friended `SourceManagerTestAccess` defined only in the test translation unit exposes this numeric helper for bounded boundary tests (no GoogleTest header or synthetic manager mode in production). Ordinary C++ allocation exceptions remain C++ failures; no Veyr OOM policy or allocator subsystem.
- Existing `veyrcore` gains `src/source/source_manager.cpp`; new `source_tests` executable uses `veyr_target_policy`, `veyrcore`, existing GTest::gtest_main/GTest::gmock and PRE_TEST discovery. Tests are defined in `tests/source/source_manager_test.cpp`; no LLVM link for this target.
