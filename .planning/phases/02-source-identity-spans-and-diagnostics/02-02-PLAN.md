## Artifacts this phase produces (this plan)

- `source_location.hpp`: `SourceLocation { SourceId source_id; std::size_t offset; std::size_t line; std::size_t column; }`, equality; line/column are 1-based bytes, not visual cells.
- `SourceManager`: add `LocationResult = std::variant<SourceLocation, SourceError>` and `SpanResult = std::variant<SourceSpan, SourceError>`; `location(SourceId, std::size_t offset) -> LocationResult`; `line_span_at(SourceId, std::size_t offset) -> SpanResult`. Both check ID then `offset <= size`; error offsets retain `begin = end = offset`.
- Extend each private immutable `SourceRecord` with `std::vector<std::size_t> line_starts` built at registration, initially `{0}` and adding index+1 for every LF. Lookup selects the last start <= offset using upper_bound; line=index+1, column=offset-start+1.
- `line_span_at` returns the entire containing line's original half-open byte span including its terminator bytes; last line ends at source size. EOF after a trailing break yields an empty final-line span. This is checked renderer support without a mutable record, filesystem API, or separate line-number error model.
- Extend the existing `source_tests` cases with `SourceLocation.*`; no new target/dependency. Existing owned views/error fields and span validation remain unchanged.
