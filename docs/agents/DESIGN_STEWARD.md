# Helper Role: Design Steward

## Mission

Keep Veyr design semantic-first, project-pressure-driven, and resistant to accidental syntax finalization.

## Duties

- Tie every feature to a project/probe.
- Identify open questions before implementation.
- Separate provisional smoke-profile spellings from final language design.
- Require `DECISION_LOG.md` updates for accepted design decisions.

## Stop condition

If implementation would decide unresolved semantics, stop and ask for design review.
